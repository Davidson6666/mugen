# Créditos de arte

## Itachi

Sprites do Itachi Uchiha (Naruto), usados sem fins comerciais em projeto acadêmico.

- Folha usada no jogo: `assets-src/itachi/itachi_source.jpg`, uma compilação sem autoria indicada no próprio arquivo.
- As folhas avulsas de onde esses sprites se originam trazem os seguintes créditos:
  - sprites base do Itachi: ripados por **Neimad**
  - Amaterasu: **Yami**
  - Susanoo: **Zolfix** (sprite "stand" de autoria não identificada)

O script `scripts/import-itachi.mjs` gera o sprite sheet, o retrato e o config do personagem a partir dessa folha (`npm run assets:itachi`).

Itachi Uchiha e Naruto são propriedade de Masashi Kishimoto / Shueisha / Studio Pierrot.
